# TRPG人生のフルコース

あなたの卓歴を、八品に。

遊んだシナリオをコース料理に見立てて8品書き、画像（1200×1600 PNG）で保存したり、そのままXに投稿したりできる入力フォームです。

**使う → https://futakad.github.io/trpg-fullcourse/**

- 書いた内容はお使いのブラウザの中だけに保存され、どこにも送信しません
- 作った画像は、SNS・配信・動画などで自由に公開していただけます（個人・商用を問いません。クレジット表記は任意）
- 入力フォームそのものの再配布・販売、何も書いていない画像をテンプレートとして配ること、生成AIの学習データとしての利用はご遠慮ください。詳しくは [利用規約.txt](利用規約.txt)
